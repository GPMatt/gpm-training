How to use this sheet
  1. Before the walk-through, the supervisor writes the Expected quantity for every part. This is the amount the tech is responsible for keeping on the van.
  2. The supervisor and the tech count each bin together, from Bin 1 to Bin 25, and write the Counted quantity.
  3. Tick OK when Counted matches Expected. If it doesn't, write the reason in Notes (for example: short, broken, on order).
  4. List any broken items, tools and equipment below, then both people sign.
