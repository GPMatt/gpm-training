The pitch

More units per PM, without PMs doing more

GPM manages about 1,000 units with 3 property managers, roughly 333 units each. The only way that works is if routine work happens without a PM touching it, and PMs handle the exceptions.

Lane 1 · Agents act on their own

Anything that doesn't move money.
  • Text new leads a showing link
  • Triage, schedule and assign repairs
  • Keep tenants updated
  • Start the turn when notice comes in

Lane 2 · A person approves

Anything that touches trust money.
  • Agents prepare correctly coded owner bills
  • Rentvine holds every bill until a person approves it
  • A person releases payment. There's no API for it, by design

Why Rentvine and not AppFolio

GPM already has a read API on AppFolio, so agents can report. Rentvine adds write access and webhooks, so agents can act the moment something happens: update the work order, text the tenant, post the bill. Everything on the next screens is running against a real Rentvine account right now.
